# LinguaCards: Language Learning Flashcard Platform

A full-stack web application designed to help users learn foreign languages through interactive flashcards. The platform automates the process of creating, managing, and studying vocabulary decks.

## Project Context & Workflow

The system is built around distinct user interactions to ensure an effective learning flow:
* **Student Side (Learning Interface):** Users can browse available languages, select vocabulary decks, and view interactive flashcards to test their knowledge and memorize translations.
* **Creator Side (Content Management):** Authenticated users have a dedicated interface to create custom decks, add new cards (word + translation), and update their existing materials.
* **Admin Side (Management Panel):** Restaurant staff and managers utilize a secure interface to manage the global list of languages and moderate user-generated content (Full CRUD operations).

## Core Technologies

* **Backend Framework:** Django
* **API Development:** Django REST Framework (DRF)
* **Frontend Rendering:** Django Templates
